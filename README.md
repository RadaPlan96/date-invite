# Date Invite Game

Ένα μικρό, mobile-first παιχνίδι/πρόσκληση για ραντεβού, έτοιμο για GitHub Pages.

## Προσαρμογή

Άνοιξε το `config.js` και άλλαξε μόνο:

- `recipientName`: το όνομά της
- `dateIdea`: την αρχική πρόταση που θέλεις να εμφανίζεται
- `formEndpoint`: το endpoint που δίνει το Formspree για τις email ειδοποιήσεις

## Ανέβασμα στο GitHub Pages

1. Δημιούργησε νέο public repository στο GitHub.
2. Ανέβασε τα τέσσερα αρχεία του φακέλου στη ρίζα του repository.
3. Πήγαινε **Settings → Pages**.
4. Στο **Build and deployment**, επίλεξε **Deploy from a branch**, branch **main**, φάκελο **/(root)** και πάτησε **Save**.
5. Σε λίγο θα εμφανιστεί το δημόσιο link της σελίδας.

Μετά το «Ναι» εμφανίζονται τρεις επιλογές: καφέ, ποτό/κρασί και φαγητό. Στη συνέχεια η Ειρήνη επιλέγει ημερομηνία/ώρα και γράφει το μέρος. Η πρότασή της στέλνεται με Formspree στο email που έχεις δηλώσει εκεί. Η επιλογή «Όχι» αποφεύγει το πάτημα τρεις φορές για το αστείο και μετά λειτουργεί κανονικά.

## Σύνδεση ειδοποίησης

1. Δημιούργησε λογαριασμό στο Formspree.
2. Φτιάξε νέο form και επίλεξε το email στο οποίο θέλεις να λαμβάνεις τις απαντήσεις.
3. Αντέγραψε το endpoint της φόρμας, π.χ. `https://formspree.io/f/abcdwxyz`.
4. Στο `config.js`, αντικατάστησε το `https://formspree.io/f/ΑΛΛΑΞΕ_ΜΕ` με το δικό σου endpoint.
